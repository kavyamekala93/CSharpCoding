### In Big O, we ignore constant multipliers.
```text
Compare three scenarios
1. Two HashSets based on the same array
O(n) + O(n) = O(n)
2. Two HashSets based on two independent arrays
O(n) + O(m) = O(n + m)
3. One HashSet and one integer variable
O(n) + O(1) = O(n)
Important distinction
Time complexity measures how much work the algorithm performs.
Space complexity measures how much additional memory the algorithm uses.
```text
